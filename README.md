# HousePrices
RnD in ML course, ITMO

Как запустить:
```bash
git clone https://github.com/tarma3v/HousePrices.git
cd HousePrices
poetry install
bash scripts/run_baseline.sh
```

Требования:
Kaggle аккаунт, Kaggle API токен в ~/.kaggle/kaggle.json (или в Environment variable), принять правила соревнования: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

Без Kaggle API: скачайте архив вручную со страницы соревнования и распакуйте
`train.csv`, `test.csv`, `data_description.txt`, `sample_submission.csv` в `data/raw/`.

Задача: предсказать цену дома по его характеристикам (от типа здания и площади до качества гаража, бассейна и забора).

Гипотеза 1: решения на основе деревьев - градиентный бустинг 
или случайный лес покажут лучшую метрику RMSE(log предск. цены - log цены), чем линейная регрессия в K-fold кросс-валидации, так как может лучше определять зависимости в пространстве (качество жилья, размер жилья).

Гипотеза 2: knn на небольшом количестве параметров и со скейлингом покажет лучшую метрику RMSE(log предск. цены - log цены), чем 
- knn, обученный на всех параметрах (так как не все параметры важны и могут добавлять лишний шум) 
- бейзлайн 1 (медиана по району), так как будет учитывать больше параметров.


baseline 1
медианная цена дома в этом районе (на тестовой выборке, если района не было, то просто медиана) - ожидается, что дома по соседству с похожими характеристиками будут иметь похожую стоимость.

baseline 2
линейная регрессия (с убранными скореллированными признаками, выбрать итоговый список после EDA на тренировочных данных)

baseline 3
knn с базовыми признаками дома - тип здания, площадь, район
